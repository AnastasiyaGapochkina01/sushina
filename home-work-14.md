1) Запустить статический сайт https://gitlab.com/devops201206/it-mtb-blog на ВМ с помощью nginx
2) После того, как сайт запущен по простому http, сгенерировать самоподписанные сертификаты для nginx с помощью утилиты `openssl` и настроить доступ к сайту через https на сгенерированных сертификатах\
> [!NOTE]  
> Проверять можно с помощью curl с ключом -k (игнорирует ошибки сертификата - тк сертификат у нас самоподписанный)
3) Ознакомиться с 
- [уроком](https://youtu.be/H486uBDG1pc) и по его мотивам запустить свой secure docker registry на самоподписанных сертификатах
- [уроком](https://www.youtube.com/watch?v=ZiuGR30B7kU) С 46 МИНУТЫ - и если есть свой домен, то запустить harbor на нормальном сертификате
4) Собрать кластер redis из двух нод с доступом между ними по tls (как точку опоры можно использовать [статью](https://medium.com/@ozcankasal/setting-up-a-redis-cluster-with-tls-e02d53d9faa7))
