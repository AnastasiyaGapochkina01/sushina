- https://kubernetes.io/docs/tasks/tools/

2) Запустить через манифест pod с контейнером prometheus
3) Вывести состояние запущенного пода
4) Посмотреть логи контейнера внутри пода
5) Добавить к поду сервис, через который будет доступ к промику; проверить, что доступ есть
6) Удалить под и сервис
7) Запустить под с двумя контейнерами
- mongodb
- mongo-express

8) Проверить, что из mongo-express можно постучать в mongodb по ее порту
9) Написать манифест для репликасета, который запускает 4 реплики из image `anestesia01/k8s-demo:time-app-2.0.0`; применить его
10) Проверить поведение репликасета при убийстве подов
11) Создать namespace `time`
12) В созданном namespace `time` запустить репликасет и сервис для приложения из image `anestesia01/k8s-demo:greet-app-1.0.0`
